# DKM Learning Hub — audit audience & autorité v1

Date : 2026-07-15
Auteur : Hermès
Contexte : analyse du site public `https://dkm-learning-hub.vercel.app` après navigation sur la home, la fiche du cours, une leçon, les ressources, le générateur Soul Document et la section Projets & Labs.

## 1. Verdict

Le site a déjà une base solide pour construire une autorité DKM autour de l’IA concrète.

Ce qui fonctionne déjà :

- Positionnement clair : apprendre l’IA comme un builder, pas comme un spectateur.
- Design premium et éditorial : fond ivory, ink profond, terracotta, typographie expressive, cartes sobres.
- Parcours `Architecture IA : du neurone à l’agent` crédible et structuré.
- Ton accessible : les titres expliquent des confusions réelles au lieu d’empiler du jargon.
- Présence de projets réels via `Projets & Labs`, ce qui renforce la preuve que DKM construit avec l’IA.
- Ressource Soul Document très pertinente comme outil de capture et de transformation.

Point principal : le site démontre déjà de l’expertise. La prochaine étape est de transformer cette expertise en audience récurrente : visiteur → ressource utile → capture → apprentissage → preuve → communauté → autorité.

## 2. Positionnement recommandé

Positionnement à préserver :

> DKM Learning Hub documente l’IA concrète : comprendre les concepts, construire des workflows, apprendre à partir de projets réels.

Positionnement à éviter :

- Ne pas devenir un site IA générique avec des promesses type “10x productivity”.
- Ne pas mélanger trop directement OptiAI avec DKM Learning Hub.
- Ne pas transformer la home en page de vente agressive.
- Ne pas exposer de données client ou de détails sensibles dans les labs.

Phrase de clarification possible :

> Je construis des systèmes IA concrets, puis je transforme ce que j’apprends en cours, outils, templates et labs publics.

## 3. Constats par page

### Home

Points forts :

- Hero fort : “Apprends l’IA comme un builder, pas comme un spectateur.”
- Promesse cohérente avec l’identité DKM : God first, build in public, IA concrète.
- Trois piliers lisibles : comprendre, manipuler, construire.
- Cours vedette bien mis en avant.

Améliorations :

- Ajouter une phrase plus concrète sous la promesse pour expliciter le bénéfice.
- Ajouter trois portes d’entrée visibles : commencer le cours, générer le Soul Document, voir les labs.
- Ajouter une mini-section “Qui construit ce hub ?” pour associer l’autorité à Dennis/DKM.
- Ajouter une capture audience : email, Telegram ou liste privée.

### Cours Architecture IA

Points forts :

- Parcours très crédible : neurone → réseaux → Transformer → LLM → RAG → agents → MCP → production.
- Structure en 4 tomes / 26 modules / examen final rassurante.
- Titres de modules engageants et pédagogiques.
- Glossaire riche.

Améliorations :

- Segmenter visuellement les modules par tome.
- Ajouter une progression : module 1/26, pourcentage, modules terminés.
- Clarifier l’examen : test de niveau ou examen final ? résultat obtenu ? certificat/badge ?
- Ajouter un résumé “À retenir” en fin de leçon.
- Ajouter feedback immédiat dans les quiz.
- Rendre le résultat final partageable socialement.

### Leçons

Points forts :

- Sidebar utile pour comprendre la progression.
- Structure pédagogique forte : concept → mental model → interactif → quiz → application.
- Les interactions rendent l’apprentissage moins passif.
- Le ton est accessible, non intimidant.

Améliorations :

- Ajouter état actif/terminé/non commencé dans la sidebar.
- Ajouter un bouton “marquer comme compris”.
- Ajouter feedback visuel aux quiz : correct / incorrect / explication.
- Vérifier accessibilité clavier des interactifs.
- Prévoir une sidebar collapsable sur mobile.

### Ressources / Soul Document

Points forts :

- Le Soul Document est le meilleur actif de capture actuel.
- La promesse est utile et concrète : créer une mémoire business pour un assistant IA.
- L’outil peut prouver l’expertise DKM mieux qu’un simple PDF.

Améliorations :

- Mettre le Soul Document comme lead magnet principal.
- Renforcer la promesse : “Crée la mémoire business de ton IA en 10 minutes.”
- À la fin du générateur, proposer une action de continuité : recevoir le template, rejoindre la liste, partager le résultat, continuer vers le cours.
- Créer une version courte partageable sur réseaux sociaux.

### Projets & Labs

Points forts :

- Très bon levier d’autorité : “je n’enseigne pas juste l’IA, je construis avec l’IA.”
- Les labs Selah, Rhythm & Bible FR et Next Move/Klaris montrent des contextes différents : personnel/spirituel, pipeline IA créatif, business/client.
- La structure problème → objectif → apprentissage → prochaine étape est bonne.

Améliorations :

- Ajouter au moins un visuel par lab : architecture, workflow, capture, pipeline, schéma.
- Ajouter statut réel : idée, prototype, en construction, en validation, publié.
- Ajouter “ce qui a cassé / ce que j’ai appris” pour renforcer le build in public.
- Garder Next Move/Klaris formulé prudemment, sans donnée client ni détail sensible.

## 4. Actions prioritaires

### Priorité 1 — Capture audience

Objectif : ne plus laisser partir les visiteurs sans point de contact.

À faire :

- Ajouter un CTA global : “Rejoindre la liste DKM Builders”.
- Choisir un canal simple au départ : email ou Telegram.
- Ajouter le CTA sur la home, les ressources, la fin du Soul Document et la fin du cours.

Exemples de micro-copy :

- “Recevoir les prochaines ressources DKM.”
- “1 fois par semaine : un concept IA, un lab réel, un template actionnable.”
- “Rejoindre les builders qui apprennent l’IA concrète.”

### Priorité 2 — Humaniser l’autorité

Objectif : associer le hub à Dennis/DKM, pas seulement à une marque abstraite.

À faire :

- Ajouter une section courte “À propos de DKM / Dennis”.
- Mentionner la posture : builder IA, documentation publique, projets réels, pédagogie accessible.
- Ne pas faire une page de vente OptiAI.

### Priorité 3 — Soul Document comme lead magnet

Objectif : transformer l’outil en moteur d’audience.

À faire :

- Repositionner le Soul Document comme outil phare dès la home.
- Ajouter un CTA post-génération.
- Ajouter une page de résultat plus engageante : copier, télécharger, recevoir la prochaine ressource, continuer vers le cours.

### Priorité 4 — Preuves visuelles dans Projets & Labs

Objectif : renforcer la crédibilité par la preuve.

À faire :

- Ajouter un visuel ou diagramme par projet.
- Ajouter statut + stack + livrable associé.
- Ajouter “ressource liée” seulement quand la ressource existe ou est clairement en préparation.

### Priorité 5 — Rétention dans le cours

Objectif : faire revenir et compléter le parcours.

À faire :

- Ajouter progression locale.
- Ajouter feedback aux quiz.
- Ajouter résumé “À retenir”.
- Ajouter badge/certificat partageable après l’examen.

## 7. Prochaine action recommandée

Prochaine action unique recommandée : implémenter la capture audience minimale autour du Soul Document.

Concrètement :

1. Ajouter une section “Rejoindre DKM Builders” sur la home.
2. Ajouter le même CTA à la fin du Soul Document.
3. Choisir un canal simple : email ou Telegram.
4. Garder la promesse courte : “1 concept IA + 1 lab réel + 1 ressource actionnable.”

Cette action est prioritaire parce qu’elle transforme le site d’une vitrine d’autorité en début de machine d’audience.

## 8. Garde-fous

- Ne pas committer de secrets.
- Ne pas exécuter d’action Supabase/n8n sans validation explicite.
- Ne pas exposer de données client dans les labs.
- Séparer DKM Learning Hub de la prospection OptiAI.
- Présenter les hypothèses comme hypothèses et les faits observés comme faits.
